# Termy 1.0.0-rc.13

Same as 1.0.0-rc.12 (optional account sync), plus a CI clippy fix for the hosted
Supabase default-key guard.

## Account sync

In the X panel, open Help, then Account sync. Sign in, create an account, reset a password, or sign out. The same actions are on the CLI: `termy-xcli supabase sign-up` and `termy-xcli supabase sign-out`, along with configure, sign-in, and status.

The local action database stays primary. Sync is off until you sign in. The password is not stored. A refresh token stays in the secret store and is renewed when the panel opens.

## Clippy fix

`crates/x_core/src/supabase_defaults.rs` collapsed identical reject branches so
Architecture Checks passes under `-D warnings`. Empty, placeholder, and
`service_role` keys are still rejected. A service-role key must never be placed
in the app.

Use termy-xcli.exe, never x.exe. Image Q-tweets stay unsupported. Windows x64 only. VLC is bundled the same way as rc.12.
