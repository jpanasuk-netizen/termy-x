# Termy 1.0.0-rc.10

Release candidate prepared from the changes since `v1.0.0-rc.9`.

## Changes

### Security

- On macOS and Linux, OSC 8 hyperlinks now open only `http`, `https` and
  `mailto` links, and `file:` links that point to an existing local path.
  Other schemes (such as `smb://` or custom app schemes) are refused, matching
  Windows. Previously a program writing to the terminal could make a
  Cmd/Ctrl-click launch any scheme handler.

### Input

- On macOS, holding a key in the terminal repeats it instead of opening the
  accent-character picker, so held `hjkl` navigation works in Neovim, Yazi and
  other terminal apps (#441).

### macOS

- With `tab_style = native`, the native tab bar takes its colors from the
  terminal theme, including the glass tabs on macOS 26 and later.

### Settings

- The Built-in Multiplexer setting carries an "Early Preview" badge and asks
  for confirmation before it is turned on. Searching for "preview" or
  "experimental" finds it.

## Testing this candidate

Try held-key navigation in Neovim or Yazi on macOS, Cmd/Ctrl-clicking OSC 8
links, and the native tab bar with a few themes. Report the operating system,
architecture, and reproduction steps with any issue.

This is a pre-release. The publication workflow must mark it as such so stable
release finalization and AUR publication do not run.

## Automated packages

Supported CI packages are macOS x86_64 and arm64 (unsigned and not notarized
when Apple credentials are absent; signed only when every credential is
present), Windows x64, and Linux x86_64. The Windows x64 Setup includes
`termy.exe`, `termy-cli.exe`, and `termy-xcli.exe`. It does not include
`x.exe`. Windows ARM64 Setup is not offered: Termy embeds only AMD64 libVLC,
so neither the official win64 zip nor `vlc-3.0.24-winarm64.zip` is staged for
that target, and no arm64 Setup artifact is produced. The x64 Setup does stage
the official VLC 3.0.24 win64 runtime. That bundle includes GPL plugins; this
note does not say the combined license is cleared.
